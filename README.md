# ruta-api

Backend de mi ruta de aprendizaje en Katary Dev School. Guarda los módulos de ruta-react en SQL Server y, más adelante, los entregará con una API en .NET 10.

## Estructura

- `database/`: scripts SQL para crear la base de datos y practicar consultas.

## Herramientas

- SQL Server 2025 (edición Standard Developer).
- DBeaver para ejecutar los scripts.
